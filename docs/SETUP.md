# 小白安装教程

从头开始，一步一步来。做完大约 20 分钟，其中大部分时间在等模型下载。

---

## 第零步：你需要什么

- 一台 Windows 电脑
- 能正常登录的 U 校园账号
- 一个 DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) 注册，充个 5 块钱能用很久）

---

## 第一步：装 Node.js

打开 <https://nodejs.org/> ，下载 **LTS** 版本，一路下一步装完。

装完按 `Win + R`，输入 `cmd`，回车，然后敲：

```
node -v
```

看到类似 `v22.x.x` 就成功了。

---

## 第二步：装 Python（3.11 或 3.12）

打开 <https://www.python.org/downloads/> ，下 **3.12**。

> 别装最新的 3.13 / 3.14：faster-whisper 的部分依赖没有对应的预编译包，pip 会卡在编译上装不进去。

**安装时务必勾上最下面那个 `Add Python to PATH`**，这一步漏了后面全废。

装完在同一个 cmd 窗口敲：

```
python --version
```

看到 `Python 3.12.x` 就对了。

---

## 第三步：装转写引擎

这个负责把听力音频变成文字，是整个工具最关键的一环。

```
pip install faster-whisper==1.0.3
```

**版本号必须写**，新版 API 变了会报错。

下载慢的话先换国内镜像：

```
set HF_ENDPOINT=https://hf-mirror.com
set HF_HUB_DISABLE_XET=1
```

然后重新跑 pip 命令。

---

## 第四步：下载这个项目

把项目文件夹放到一个**路径不带中文和空格**的地方，比如 `D:\unipus`。

路径带空格会出各种奇怪问题（Chrome 启动参数被截断、Python 找不到文件等等）。

---

## 第五步：开一个调试版浏览器

**为什么要单独开一个**：Chrome 136 之后，正常启动的浏览器不允许外部程序连它的调试端口。必须用一个新的用户目录。

在项目文件夹里找到 `start-chrome.cmd`，双击运行。

它会开一个干净的 Chrome 窗口。**这个窗口没有你平时的书签和登录状态**，需要重新登录一次 U 校园。

窗口打开后，在地址栏输入：

```
http://127.0.0.1:9222/json/version
```

看到一串 JSON 就说明调试端口通了。

> 用 Edge 的话，双击 `open-edge-debug.cmd`。

---

## 第六步：启动本地服务

回到项目文件夹，双击 `serve.cmd`。

会弹出一个黑窗口，显示类似：

```
Serving at http://127.0.0.1:8787
```

**这个窗口不要关**，关了转写就用不了。

第一次转写时会自动下载 Whisper 模型（约 140MB），等一两分钟，之后再转就很快。

---

## 第七步：启动注入守护

回到项目文件夹，双击 `potato-watch.cmd`。

这个窗口**也别关**。它每 2 秒扫一次调试浏览器，发现课程页没挂控制台就把土豆注进去 —— 刷新页面、换标签都会自动补。

- 想连刷时长模块一起挂：`potato-watch.cmd --farm`
- 不想用这个，也可以走 Tampermonkey，见 [BROWSER.md](BROWSER.md)（Chrome 138 之后扩展权限常被策略禁掉，注入守护更稳）

---

## 第八步：登录并开始

1. 在调试窗口里登录 U 校园，进入任意一门课（**停在课程内容页**，不是首页）
2. 右下角会出现一颗土豆，点开
3. 「模型」框里填 DeepSeek API Key（[怎么拿](API-KEY.md)）。输入框是掩码，旁边「显」按钮可以临时亮出来看一眼；填过一次之后会加密存本地，下次不用再填
4. 「跑到第几节后停」填个数字，比如 `5`
5. 点「开始」—— 这一步会真的拉起 `node run-all.js` 进程

黑色的日志框会实时滚动，显示它现在在做什么题、拿了多少分。

---

## 常见问题

**土豆没出现**

刷新页面，等 2 秒。还是没有的话：

- `potato-watch.cmd` 的窗口是不是关了
- 按 `Alt + P` 试试（可能是被收起）
- 页面是不是 `ucontent.unipus.cn` 域（注入只认这个域）

**点开始没反应**

点「开始」之后看日志第一行。常见原因：

- `CDP 未连接` → 调试窗口没开，或者端口不是 9222
- `本地服务未连接` → `serve.cmd` 那个黑窗口关了
- `转写失败` → Whisper 模型没装好，重跑第三步

**一直显示「转写失败」**

在项目文件夹开 cmd，跑：

```
python -c "from faster_whisper import WhisperModel; WhisperModel('base.en', device='cpu', compute_type='int8'); print('ok')"
```

报什么错就搜什么错。多半是模型没下载完，或者内存不够。

**分数很低 / 0 分**

看日志里有没有 `已转写 N 字符` 这一行。

- **有** → 模型听懂了但答错了，属于正常波动
- **没有** → 音频没加载出来，脚本猜的。这题本该跳过的，属于 bug，去提 issue

**答题时页面乱跳**

正常。脚本会滚到每一题再点，视觉上看起来很忙，但不影响正确性。

**能不能最小化窗口**

刷课的时候可以放后台，但**别最小化**。最小化后浏览器会限制渲染频率，脚本的滚动事件不会真的触发，挂机会失效。

---

## 关掉的时候

1. 点土豆 →「停止」
2. 关掉 `potato-watch.cmd` 的黑窗口
3. 关掉 `serve.cmd` 的黑窗口
4. 关掉调试版浏览器

下次用重新双击这三个窗口就行，配置都还在。

---

## 不想要了

双击 `uninstall.cmd` —— 停进程、删运行期文件。

连浏览器调试目录和 Whisper 模型一起清：`uninstall.cmd --all`。

细节见 [UNINSTALL.md](UNINSTALL.md)。
