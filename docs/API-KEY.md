# 怎么拿 DeepSeek API Key

## 为什么需要它

脚本自己不听题。它用 Whisper 把音频转成英文文本，再把文本交给大模型判断：这道单选选哪个、这个空填什么、这几句话怎么排。

默认用 DeepSeek —— 便宜、中文语感好、接口稳。

---

## 获取步骤

1. 打开 <https://platform.deepseek.com/>，手机号注册或登录
2. 左侧菜单点「API keys」→「创建 API key」，名字随便填（比如 `unipus`）
3. 复制那串 `sk-` 开头的东西

> **只显示这一次**。关掉弹窗就再也看不到，先粘到记事本再关。

---

## 充值

- 左侧「充值」，支付宝 / 微信，最低 5 元
- **实测**：一屏 1~2 次调用，一册（约 160 屏）大约 **0.5~1 元**
- 控制台「环境检查」里能看到实时用量：调用次数、token 数、折算金额

先充 5 块，够跑好几册。

## 用量怎么算的

| 题型 | 调用次数 |
|---|---|
| 单选 / 多选 / 判断 | 1 次（同屏所有题打包） |
| 填空 | 0~1 次（先本地对原文，对不上才问模型） |
| 排序 | 2 次（找证据句 + 排顺序） |
| 讨论 / 说话 | 1 次 |
| 跟读 / 配音 / 上传 | 0 次 |

价格按 DeepSeek 现价折算：输入 2 元/百万 token，输出 8 元/百万 token。

---

## 填到哪里

### 方式一：土豆面板（推荐）

点开页面右下角的土豆 →「模型」框 → 粘贴 key → 点「开始」。

面板会把 key 写进项目根目录的 `control.json`，下次开跑自动带上，不用重复填。

### 方式二：control.json

打开项目根目录的 `control.json`，改这一项：

```json
{ "apiKey": "sk-你的key" }
```

### 方式三：环境变量

```cmd
set DEEPSEEK_API_KEY=sk-你的key
node run-all.js 5
```

只对当前 cmd 窗口有效。

---

## Key 存在哪、怎么加密的

填进面板后，key 不会以明文留在磁盘上。

- **落盘形式**：`control.json` 里只有 `"apiKeyEnc": "v1:..."`，没有 `apiKey` 字段
- **加密方式**：AES-256-GCM。密钥由「本机 MachineGuid + 项目固定盐」派生（见 [keyvault.js](../keyvault.js)）
- **换机器就解不开**：把项目拷到另一台电脑，需要重新填一次 key —— 这是有意为之
- **面板上不回显**：输入框是掩码，提交后立刻清空；接口 `/api/state` 只返回 `hasKey: true`，不返回明文
- **想改 key**：面板「模型」框直接填新的，点开始就覆盖

> 想临时看一眼存的是什么：`node keyvault.js dec < control.json 里的 apiKeyEnc`（同一台机器才解得开）

---

## 安全边界

这套加密防的是「打开文件就能看到 key」「投屏 / 截图被人瞄到」这类日常泄露。
它不是保险箱：能在这台机器上跑代码的人，照样能解出来。真正的兜底是在 DeepSeek 控制台随时吊销。

- 代码里**没有**硬编码任何 key，出厂状态是空的
- `control.json` 已在 `.gitignore` 里，不会被提交
- 日志里不会打印完整 key
- key 泄露了就去控制台删掉，重新建一个

---

## 能不能用别家

能。任何兼容 OpenAI `/v1/chat/completions` 格式的服务都行，改 `run-all.js` 里的这一行：

```js
const r = await fetch('https://api.deepseek.com/v1/chat/completions', { ... });
```

连同 `model` 字段一起改。注意别用太小的模型，判题准确率会掉。
