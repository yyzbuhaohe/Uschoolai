# 土豆刷课 · U 校园自动化

把新视野大学英语（U 校园 / ucontent.unipus.cn）的课后题自动做完，题型覆盖到目前能跑通的全部。

> 只对**你自己的账号、你自己的设备**有效。脚本在本地跑，不会把你的账号密码发到任何地方；API Key 用 AES-256-GCM 加密存在本地。

## 它到底做了什么

不是改网页 DOM 硬点，而是像人一样操作浏览器：

```
本地 Python 服务 (127.0.0.1:8787)
        │  调度 / 转写 / 存 Key
        ▼
Node 控制器 (run-all.js)
        │  通过 Chrome DevTools Protocol 驱动浏览器
        ▼
Chrome (--remote-debugging-port=9222)
        │
        ▼
ucontent.unipus.cn 的课程页面
```

一条题做完的完整链路：

1. **认屏**：读 `.pc-header-tab-*` 判断当前在哪个 Tab、哪个小题，数一遍页面上有几道题、是什么类型
2. **取料**：视频/音频交给 Whisper 转写成文字（带词级时间戳）
3. **想答案**：把题目和转写文本一起发给 DeepSeek，要它按固定格式回答案和依据
4. **填答案**：按题型分别处理——点选项、拖排序、填空、写作文、发评论
5. **录音回灌**：口语题没有真麦克风，用 Web Audio 造一条音频流冒充麦克风，把标准读音"喂"给页面的录音器
6. **提交**：点提交，处理确认弹窗，读分数，翻下一节

### 几个关键点

**为什么用 CDP 而不是 Tampermonkey**
这台机器上 Chrome 的扩展权限被组策略锁了（`chrome://extensions` 显示「您的家长已停用扩展程序权限」），用户脚本注不进去。所以直接开调试端口，用 CDP 从外面驱动——顺便还能做到用户脚本做不到的事（真实鼠标事件、文件上传、截图）。

**转写为什么带时间戳**
排序题和配音题都需要"哪句话在第几秒"。Whisper 的 `segments` 直接给时间，不用另外对齐。

**排序题为什么要多一步**
最初直接让模型排，准确率约 17 分——模型把语义接近的句子搞混。后来改成：先让模型给每条陈述找一句**证据句**，再用证据句的时间戳排序。多一次模型调用，但 4/4 全对，100 分。

**口语题怎么"说话"**
页面用 `getUserMedia → createMediaStreamSource → RecorderJS` 录音。我们劫持 `getUserMedia`，返回一条自己造的 `MediaStreamDestination` 流，再把 TTS 或视频音轨接进去。关键细节：音频节点**必须挂一条支路到 `destination`**，否则 Web Audio 不渲染这条链，ScriptProcessor 一个采样都收不到，页面就会弹「录音启动超时」。

**配音题怎么处理**
页面里每句自带一支 `<audio>` 示范音。把它接进页面的音频图，录进去的就是标准读音。长度直接读 `audio.duration`，比从视频里猜时间点准。原速播放，**不能加速**——加速会让评分引擎的时间轴对不上，后半句被判成没读。

## 快速开始

### 0. 准备

- Windows 10/11
- Python 3.11 或 3.12（**3.13 装不上 faster-whisper**）
- Chrome 或 Edge
- 一个 DeepSeek API Key（[怎么拿](docs/API-KEY.md)）

把整个文件夹放到**路径不带中文和空格**的地方，比如 `D:\unipus`。

### 1. 一键装环境

双击 `install.cmd`。

它会：装 Python 依赖（faster-whisper、Flask 等）→ 预下载语音模型 → 检查文件齐不齐 → 建桌面快捷方式。

### 2. 开一个调试浏览器

双击 `start-chrome.cmd`（用 Edge 就双击 `open-edge-debug.cmd`）。

会开一个**独立的** Chrome 窗口，配置存在 `C:\chrome-debug`，跟你平时的浏览器互不干扰。第一次要在这个窗口里重新登录 U 校园。

### 3. 起服务

双击 `serve.cmd`，浏览器打开 <http://127.0.0.1:8787/> 就是控制台。

第一次进去填 API Key，它会加密存到 `control.json`（明文不落盘）。

### 4. 注入 + 开跑

双击 `potato-watch.cmd`（保持窗口开着），然后回控制台点「开始」。

之后它自己一屏一屏往下做。

## 常见问题

**「录音启动超时」**
页面点录音后 15 秒内收不到音频数据就会弹这个。检查 `potato-watch.cmd` 是不是在跑（它负责注入钩子），或者重启一次服务。

**分数低**
- 口语/配音：页面只认第一次作答，重录也不会覆盖
- 选择题：模型偶尔会错，尤其题目本身有歧义时
- 排序题：改写幅度大时证据句可能找偏

**卡住不动**
看控制台的日志。常见原因是网络断了，或者页面弹了没见过的弹窗。

**能同时开两个吗**
不能。一个调试端口只能挂一个会话。
